## Задание 3697
Все 5-⁠буквенные слова, составленные из букв В, И, Н, Т, записаны в алфавитном порядке и пронумерованы. Вот начало списка:
1.  ВВВВВ
2.  ВВВВИ
3.  ВВВВН
4.  ВВВВТ
5.  ВВВИВ
...
Запишите слово, которое стоит под номером 1019.
```
a = 'ВИНТ'
c = 0
for i in a:
    for j in a:
        for k in a:
            for l in a:
                for m in a:
                    s = i + j + k + l + m
                    c += 1
                    if c == 1019:
                        print(s)
print(c)
```

## Задание 25840
Вася составляет 4-⁠буквенные слова, в которых есть только буквы Б, Е, Л, К, А, причём буква Б используется в каждом слове ровно 1 раз. Каждая из других допустимых букв может встречаться в слове любое количество раз или не встречаться совсем. Словом считается любая допустимая последовательность букв, не обязательно осмысленная. Сколько существует таких слов, которые может написать Вася?
```
a = 'БЕЛКА'
c = 0
for i in a:
    for j in a:
        for k in a:
            for l in a:
                s = i + j + k + l
                if s.count('Б') == 1:
                    c += 1
                    print(s)
print(c)
```
